# Jeu de démonstration

Données **entièrement fictives** (récits, personnes) pour voir l'application remplie sans rien enregistrer :

```bash
uv run au-fil-d-une-vie --demo
```

Le fichier est embarqué dans le paquet : [`src/au_fil_d_une_vie/data/demo.json`](../src/au_fil_d_une_vie/data/demo.json). Aucune vraie voix ni donnée réelle ne doit y être ajoutée.
